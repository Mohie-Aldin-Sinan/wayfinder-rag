Loads or creates a SentenceTransformer model that can be used to map text and other inputs to dense embeddings.


Compile the model’s forward pass with
torch.compile()
to speed up inference.
All arguments are forwarded to
torch.compile()
. Inference (e.g.
encode()
or
predict()
) runs the forward pass by calling the model, so compiling the model speeds up these calls.
Tip
Pass
dynamic=True
for inputs with variable sequence lengths, so one compiled kernel handles any length. Explicit
dynamic=False
recompiles the model for every new sequence length, which adds significant overhead.

Computes embeddings for the given inputs.
Tip
If you are unsure whether you should use

,

, or

This training approach uses a list of DataLoaders and Loss functions to train the model. Each DataLoader is sampled in turn for one batch.
