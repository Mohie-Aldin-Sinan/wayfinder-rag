Find the right paragraph, then answer from it.

Wayfinder is a retrieval-augmented generation pipeline built so each stage can be measured on its own. If an answer is wrong, the evaluation shows whether retrieval found the evidence or generation used it badly.

View the code See the numbers

01 · Pipeline

Eight stages, each replaceable.

  1. 01DocumentsMarkdown from official docs
  2. 02Token chunkingFixed-size, overlapping chunks
  3. 03Local embeddingsRuns without a paid API
  4. 04Dense retrievalVector search in Qdrant
  5. 05Lexical BM25Keyword matching
  6. 06Rank fusionReciprocal-rank fusion of both lists
  7. 07Cross-encoder rerankReorders the top candidates
  8. 08Grounded generationAnswers cite the retrieved chunks

Retrieval and generation are scored separately, so a bad answer can be traced to the stage that caused it.

    04 · Notes

    What this does and does not show.

    • The benchmark is small and was built by the author, so treat the figures as an early signal rather than a general claim.
    • Relevance labels point to specific chunk IDs, so a correct answer from a different chunk counts as a miss.
    • Latency has not been measured yet. Indexing a larger corpus is listed as future work.
    • This page shows recorded results. It does not run the pipeline live.
